# Turbo C (C Programming)

Legacy C programming archive containing standalone exercises, course work, projects, and Turbo C-era support files.

## Repository structure

- `programs/standalone/` — standalone C/C++ exercises that were previously stored in the repository root.
- `projects/maze-x11/` — the Maze/X11 sample and its Makefile.
- `archive/backups/` — historical `.BAK` files.
- `archive/imports/` — imported/archive packages such as ZIP files.
- `docs/` — text and document files.
- `assets/` — icons and images.
- `legacy/turbo-c-root-headers/` — Turbo C header files formerly stored at the root.
- `legacy/turbo-c-support/` — Turbo C support/configuration/runtime files formerly stored at the root.
- `legacy/devcpp/` — legacy Dev-C++ project/build files.

Existing course folders and the historical Turbo C directories (`BGI/`, `INCLUDE/`, `LIB/`, `SYS/`, `TC/`, etc.) remain in their original locations so old references are less likely to break.

## Notes

Many programs in this repository were written for older Turbo C / DOS-era environments. Some may require compatibility changes before compiling with a modern C/C++ compiler.
